Fast to play.
Careful with state.

A local, difficulty-aware engine chooses automatic opponent moves in both the ChatGPT widget and standalone preview. The server checks each move and returns the saved board with a confirmation receipt.

01 · CHOOSE

Set the match

Choose the game, color, board size where relevant, and Easy, Medium, or Hard before starting.

02 · PLAY

Tap exact moves

Available intersections, squares, columns, shots, and safeties come from the current authoritative snapshot.

03 · CONTINUE

Resume safely

Versioned saved sessions reconcile after reloads. Reset and End Game require a clear confirmation.

04 · IMPORT

Continue a Go board

Attach a Go-board image in ChatGPT, inspect the transcription, then approve the position before either side moves.

05 · FIT

Made for the pane

Chess and smaller boards use a landscape-aware layout, while 19×19 Go remains fully visible without forced scrolling.

06 · VERIFY

Receipts, not guesses

Version and reset-epoch checks reject stale actions; ambiguous mutations are never blindly repeated.
